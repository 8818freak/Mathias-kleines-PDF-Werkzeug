User manual · English

Mathias' kleines PDF-Werkzeug

Seventeen tools for one recurring problem: turning scanned documents into a clean, correctly formatted PDF file after the fact — straighten, split apart, reassemble, bring to a standard size, shrink. This manual walks through every tool using a real example.

Tools also reachable via menu All tools are also available from the Tools menu, in addition to the sidebar. The sidebar itself can be shown/hidden via View → Show tool list resp. Cmd+Alt+L (⌘⌥L) -- handy for gaining more room for the file list and tool area on smaller screens.

Tool 01

Create PDF

The starting point for practically every session: PDF files, JPGs, BMPs, and TIFFs (including multi-page ones) are loaded via drag & drop into a shared file list and combined into a single PDF in exactly that order. This list is the hub of the whole app — every other tool keeps working on the same list, without needing to export and reload in between.

  1. Load files via Add files … or drag & drop into the middle list.
  2. Change the order by dragging within the list, if needed, or reverse it entirely via Edit → Reverse order (with pages selected, just their order among each other).
  3. Optional: prepare with other tools (rotate, split, normalize) — the list is preserved throughout.
  4. Click Export as PDF … and choose where to save.
Lossless where possible Unmodified PDF pages rotated by 0/90/180/270° stay vector pages on export — only truly free rotation angles, mirroring, or splits get rasterized.

Tool 02

Rotate pages

Straighten crookedly scanned pages directly with the mouse: dragging in the preview rotates the page freely, fixed, colored reference lines (color freely selectable) act as a spirit level. Plus the usual quick actions — 90°, 180°, mirror — as well as a function for double-page spreads that were scanned sideways in alternating directions.

  1. Click a page in the list, then drag with the mouse button held down in the preview until the content lines up with the reference lines.
  2. Color of the reference lines selectable above the preview (six small color buttons) -- handy for colored originals where the default color is hard to make out.
  3. For exact values: use the number field below the preview, or fine-tune with the arrow keys in 0.1° steps (Shift (⇧)+arrow = 1° steps).
  4. For right angles/mirroring: use the quick-action buttons.
  5. Set the scope (current page / selection / all) above the list before applying a quick action.
  6. For sideways-scanned double-page spreads with alternating orientation: apply Rotate alternately by 90° to the whole selection.
  7. For large batches: Detect skew automatically suggests the angle via text-line detection (still adjustable afterward by mouse or number field); pages without a reliably detectable line pattern (photos, graphics-heavy pages) are left unchanged.
Apply fine angle Copies the exact angle of the current page onto the selected scope — handy when several pages from the same stack share the same slight skew.

Tool 03

Image cleanup

For scanned black-and-white/text originals: converts to pure black and white (threshold, optionally auto-suggested via Otsu's method) and/or removes small dark specks (dust, print artifacts). Both steps can be toggled independently.

  1. Select a page — the preview immediately shows how threshold, binarizing, and despeckling affect exactly this page.
  2. Suggest automatically computes a threshold via Otsu's method that most clearly separates text/lines from the background — or fine-tune it by hand.
  3. Turn off Convert to pure black and white (binarize) if needed, to only remove specks while leaving gray/color values otherwise unchanged.
  4. Choose a scope and click Apply.
Smaller files as a side effect Binarized pages can often be compressed especially small in "Shrink PDF & PDF/A" — pure black-and-white content needs far less storage than a grayscale or color scan.

Tool 04

Remove blank pages

Searches the selected scope for likely blank pages (via ink share) — typical with automated ADF scanning (duplex with an occasionally unprinted back side, blank separator sheets). Only finds suggestions, doesn't delete anything automatically: the pages found appear in an overview with checkboxes (all preselected), so individual pages can be deselected before actually removing them.

  1. Choose a scope (usually All pages, since one typically checks the whole freshly loaded batch) and click Search for blank pages.
  2. Each page found appears in the overview with a checkbox and its measured ink share — all checked by default.
  3. Deselect whatever isn't actually a blank page.
  4. Click Remove selected.
Threshold and sensitivity adjustable The ink threshold (what counts as "ink") and the maximum share (at what point a page counts as "blank") can be adjusted — handy for scanners with visible noise/dust that would otherwise falsely flag real, nearly blank pages.

Tool 05

Split pages

Cuts a page along vertical and/or horizontal lines into a row-by-column grid — e.g. for two book pages on one double-page scan, or several form fields on one scanned sheet. The cut lines are dragged with the mouse, with zoom for pixel-precise placement.

  1. Set the number of columns and/or rows, click Apply — the lines appear evenly distributed.
  2. Drag each line individually with the mouse; to hit precisely, zoom in with Ctrl/Cmd (⌃/⌘)+scroll resp. a pinch gesture.
  3. Auto-align pulls each line to the quietest (emptiest) nearby image area — good for a booklet's gutter instead of the middle of the text.
  4. Apply split now actually cuts the page apart; the parts replace the page as independent, further-editable entries in the list.
Mind the order Until applied, the split is only a setting — until then the page can still be exported normally (then split automatically) or the split removed again.

Tool 06

Combine pages

The counterpart to the split tool: several smaller scans — e.g. A4 sheets of an A1 drawing or a schematic — are assembled into one large page. One click produces an initial edge-to-edge layout; afterwards, each part can be freely dragged, fine-rotated, and cropped at the edges.

  1. Select the parts in the file list in the desired reading order (Cmd (⌘)/Shift (⇧)-click).
  2. Set the number of columns (e.g. 2 for a 2×2 grid from four parts) and click Generate layout from selection.
  3. Click each part in the preview (selects it) and drag it to the right place with the mouse.
  4. For the selected part, set a fine rotation (0.1° steps) and a crop per edge in % on the right, to compensate for slightly different scan edges or a deliberate overlap.
  5. Apply replaces the originally selected parts with the one assembled page.
Rotation as a number field, deliberately For technical drawings, an exact degree value is more precise than a mouse click — the "Rotate pages" tool remains useful for the rough alignment of individual parts regardless, and factors in automatically here.

Tool 07

Split booklet pages

For stapled booklets available as double-page spread scans in their physically stacked order (scan 1 shows the last and the first book page, scan 2 the ones before and after that, and so on): this tool automatically splits every double-page spread down the middle and puts both halves into the correct reading order — following the classic saddle-stitch formula.

  1. Select all double-page scans of the booklet in their physically stacked order.
  2. If scanned sideways (alternating by 90° in alternating directions): check Scans were scanned sideways.
  3. Click Split + sort selected scans.
  4. If a scan is clearly wider than the others (cover with foldout part): the same drag editor as in the split tool opens automatically — set as many cuts as needed there and specify which parts belong to the left resp. right target page. Placement then happens fully automatically.
Where the formula comes from A saddle-stitched booklet with n sheets gives sheet i (0-based) the target pages n−i (left) and i+1 (right) for even i, swapped for odd i — exactly matching how it is physically folded and stapled.

Tool 08

Number pages

For a scrambled page sequence — manually assign each page a target number, then rearrange in one step. Nothing is written onto the page, only the order in the list changes. Alternatively: automatic sorting by capture/creation date, including renaming the files on disk.

  1. Click a page, enter the target number, click Assign & next — automatically jumps to the next page.
  2. Once all pages are assigned: click Rearrange now.
  3. Alternatively, if capture/file date gives the correct order: Sort automatically by capture/creation date.
  4. To also rename the original files on disk: Rename files on disk by date ….

Tool 09

Set bookmarks

For booklets and books one already goes through page by page anyway: optionally give each page a chapter or sub-chapter title. Automatically becomes a bookmark/table of contents (outline) in the PDF file when saving — with no separate export step.

  1. Select the page that starts a chapter or sub-chapter, enter a title.
  2. Choose a level — Chapter or Sub-chapter — then click Set & continue; automatically jumps to the next page.
  3. The overview below shows every bookmark set so far in page order — click one to jump to that page.
  4. Automatically carried over into the PDF file as an outline the next time it's saved.
No separate export needed Unlike other tools, there's no dedicated "Apply" button here — bookmarks automatically flow into every save, whether via "Create PDF", "Save", or "Shrink PDF & PDF/A".

Tool 10

Normalize page size

Brings pages to an exact physical size — a DIN A format, a US format (Letter, Legal, …), or a custom size. Portrait and landscape orientation are detected automatically per page. Black scan borders, such as those that appear when the original was smaller than the scanner bed, are automatically detected per edge and cropped away; without a detectable border, the page is scaled directly.

  1. Click a page — the tool automatically measures the current (content) size and suggests a matching format, if one is close enough (DIN A or US).
  2. Use measured size sets this suggestion directly as the target size — or choose a format resp. a custom size by hand.
  3. Set the output resolution (dpi) and whether black borders should be cropped.
  4. Choose the scope and click Apply.
  5. Alternatively: enable Automatically detect format per page -- then each page determines its own target format (rounding to the nearest known format), instead of using one chosen format for all.

Portrait/landscape detected automatically Format detection only compares the short and long side, regardless of orientation — an A4 sheet is recognized the same way whether it was scanned upright or sideways. When applying, the target size is automatically adapted to each page's actual orientation (a page detected as landscape gets the landscape variant of the target format) without rotating the page itself. A file with a mix of portrait and landscape scans can therefore be normalized in a single pass.
All formats always available DIN A and US formats are both available for selection at the same time, regardless of the configured measurement unit — only the display of the numeric values follows the measurement unit chosen under Preferences (millimeters or inches), not which formats are on offer.
Several sections, different formats For a document with, say, A4 inner pages and an A3 insert: either run the tool once on the A4 pages (select, A4, Apply), then again with a different selection and A3 -- or more simply, enable Automatically detect format per page and apply once to all pages at the same time: each page is then normalized to its own, automatically detected format.

Tool 11

Crop pages

Crops pages on all four edges by a freely chosen amount — e.g. to precisely remove a punch-hole strip or binding margin. Unlike "Normalize page size", this does not scale to a target size but cuts away exactly the specified amount; the resulting size follows from that and is displayed live.

  1. Enter the four margins as number fields (Left, Top, Right, Bottom) — or drag the yellow lines directly in the preview with the mouse.
  2. To hit precisely with small margins: zoom in with Ctrl/Cmd (⌃/⌘)+scroll resp. a pinch gesture.
  3. The resulting size is shown live below the margin fields, including a format suggestion if one fits.
  4. Choose the scope and click Apply — the same margins are applied to every page within the selected scope.
Fixed margins persist The configured margins persist when switching to the next page — handy for deliberately applying the same fixed amount to several, slightly different-sized pages ("in bulk").

Tool 12

Redact

Permanently obscure any number of areas on a page: fully filled rectangles, freely drawn, moved, and resized with the mouse. Unlike a plain black box, the rectangles are actually burned into the image pixels on save — affected pages are automatically rasterized for this, even if they'd otherwise export losslessly as a vector page, so no original text is guaranteed to remain underneath.

  1. Dragging on empty space draws a new rectangle; clicking an existing one selects it.
  2. Dragging inside moves the selected rectangle, dragging a corner resizes it.
  3. Delete selected rectangle resp. Delete all on this page removes them again.
  4. Transfer copies the current page's rectangles onto a chosen scope of further pages — handy for recurring information (e.g. a case number at the top of every page).
Really permanent The color is selectable in Preferences (default: black), but always fully opaque with no transparency — what's redacted is irrevocably gone from the saved file, not just covered up.

Tool 13

Split PDF into images

The way back out of a PDF: save the shared file list as individual, sequentially numbered image files (PDF, JPEG, TIFF, or BMP per page) or as one multi-page TIFF file — e.g. for further processing that expects individual image files instead of a PDF.

  1. Export as individual numbered files … for separate files — choose format, base name, start number, and digit count in the following dialog.
  2. Or Export as one multi-page TIFF file … for a single file containing all pages.

Tool 14

Shrink PDF & PDF/A

Three separate, independently usable functions: significantly reduce the file size of large scans via JPEG encoding (quality and maximum resolution selectable — already efficiently compressed black-and-white pages are automatically passed through unchanged, since JPEG would usually be both bigger and worse there), losslessly compress an existing PDF's structure, or mark a PDF with the markers for the PDF/A-2b archival format.

  1. For smaller files: set JPEG quality and maximum resolution, Export as smaller PDF ….
  2. If the result isn't smaller than the original, the app points this out — usually a sign that the source was already efficiently compressed; then lower quality/resolution further.
  3. For archival marking: choose an existing PDF file, Mark existing PDF file as PDF/A-2b ….
  4. For lossless compression with zero quality loss: Losslessly compress existing PDF file ….
No formal certification The PDF/A marking sets the usual markers recognized by software, but is not a formal veraPDF certification — for binding archival requirements, additionally verify with a dedicated checking tool.

Tool 15

Repair & unlock PDF

Three separate, independently usable functions that only belong together thematically (damaged resp. locked files): repair a PDF file that can no longer be opened; remove a file's password protection when the password is known; or recover a forgotten password (dictionary attack or brute force).

  1. Repair PDF: choose the damaged file, choose a target location, Repair damaged PDF file … — reconstructs a broken cross-reference table or a faulty file ending, the most common causes of "PDF won't open".
  2. Remove password: choose the file, enter the known password, choose a target location — saves an unencrypted copy.
  3. Recover password — dictionary attack: choose the file, optionally add a wordlist (one candidate per line) and/or have your own password log searched.
  4. Recover password — brute force: choose character types and a length range, first click Estimate search space & duration (measures the actual speed on this file), only then Start search … — can be stopped at any point via the Cancel button in the progress window.
A repair is no substitute for a backup For very badly damaged files (e.g. cut off while saving, with no page structure left at all), even this function can't rescue them.
Brute force grows extremely fast Every additional character of length multiplies the number of combinations by the size of the chosen character set — always estimate first before starting a possibly hopeless run.

Tool 16

Password protection

Four separate functions that share one set of encryption settings (method, permissions password, permissions): add a password to a single file, encrypt an entire folder including subfolders, encrypt files based on a list, and keep a log of passwords that have been set.

  1. Encryption settings (top, apply to all three actions): method (RC4 40/128-bit or AES 128/256-bit — AES 256-bit is the default), an optional permissions password (if left blank, the user password also acts as the permissions password), plus individually allowing or blocking printing/copying/editing.
  2. Protect a single file: enter a user password, choose the file, choose a target location.
  3. Encrypt folder: enter a password, choose a folder — encrypts ALL PDF files in it and all subfolders directly in the original files, not as a copy.
  4. Encrypt from list: choose a CSV file (columns "file path;password" — an exported log file fits directly) — encrypts every named file directly with its own password.
  5. Password log: automatically remembers which file was given which password. Show passwords toggles them visible, Export/Import log … exchanges it as a CSV file.
Folder and list act directly on the originals Unlike with a single file, no target location is asked for here — the PDF files found are encrypted directly. Make a backup first if the files are still needed unencrypted elsewhere.
The log is plaintext The password log is deliberately stored unencrypted — convenient for your own records, but not a vault. It lives in the program's settings and can be exported, imported, or cleared entirely at any time.

Tool 17

Edit metadata

Unlike every other tool, a single set of values applies to the whole document here, not per page: title, author, provider, product, version, release date, and keywords. PDF only has a fixed number of standard fields — the preview shows exactly how these values actually flow into them.

  1. Enter title, author, and provider — provider is prefilled with the default set in Preferences (otherwise with the one most recently used).
  2. Add product, version, and optionally a release date — PDF doesn't have a dedicated field for these, so they automatically flow into the keywords instead (see the preview further down in the tool).
  3. Applied automatically on every save — no separate Apply button needed.
  4. "Save As" automatically suggests a filename from these, e.g. "Product - Title vVersion (Date).pdf".
Provider & date format configurable Under Preferences, a default provider can be set, along with the date format for the release date (e.g. YY-MM or YYYY-MM-DD).

Preferences

The menu Edit → Preferences … (on macOS automatically moved into the application menu, keyboard shortcut Cmd+, (⌘,) resp. Ctrl+, (⌃,)) lets you set the interface language, measurement unit, date format, default provider, and redaction color. Language and measurement unit stay deliberately switched by hand instead of being taken automatically from the system settings, since the PDFs being edited can come from any country, regardless of how this computer is set up.

  1. Language: German (default) or English — takes effect only after restarting the program.
  2. Measurement unit: Millimeter (default) or Inch — takes effect immediately, even while "Normalize page size" is already open.
  3. Date format: for the release date in the "Edit metadata" tool (filename suggestion and keywords) — YY-MM, YYYY-MM-DD, or DD.MM.YYYY.
  4. Provider (default): prefill for "Provider" in the "Edit metadata" tool — leave blank to always suggest the provider most recently entered there instead.
  5. Redaction color: color for newly burned-in redactions in the "Redact" tool — clicking it opens the system's own color picker (a color wheel on macOS).
Why not automatic? A computer bought in the US but set to German just as often processes European scans as American ones, and vice versa — the system language/region says nothing about the origin of a specific PDF. That's why switching this stays deliberately manual.

System requirements

PlatformMinimum
macOS11 (Big Sur), 64-bit — Apple Silicon or Intel
Windows10, 64-bit

About 250 MB of free disk space for the program, plus free space for temporary files while working (roughly 2 to 3 times the size of the PDFs being processed). No internet connection and no additional software needed (no Python, no ImageMagick/Ghostscript) — both program versions are fully self-contained.

Note on Windows Developed and tested exclusively on macOS — the Windows version is not tested by the author, but hopefully works correctly. If you run into a bug, please report it with a precise, reproducible description to telefonmann@telefonanleitungen.de, and it will be fixed as soon as possible.
